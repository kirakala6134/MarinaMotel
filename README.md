# Marina Otel

Marina Otel adındaki hayali otelimizin web sitesi ve admin panelini içeren bir projedir. Asıl amacı böyle bir işletmenin hem kullanıcı tarafında web sitesi ile rezervasyon işlemlerini kısaltmak hem de admin tarafında kolaylıkla süreci takip edebilmek için yapılmış bir projedir. Sevgili AI babacan oldukça yardım etmiştir.
